# AI Agents Governance Template

Este é um template avançado de Governança para desenvolvimento guiado por agentes de IA (Spec-Driven Development) contendo papéis para Analista, Arquiteto, DBA, Tester, Desenvolvedor, Reviewer, SecOps e DevOps.

Para usar, basta copiar a pasta .agents e o arquivo AGENTS.md para a raiz do seu novo projeto.
